================================================================================
LITTLE KRISHNA'S BUTTER HUNT - ASSET GENERATION PROMPTS
================================================================================

How to use this file:
  1. Paste the STYLE PREAMBLE at the start of every prompt.
    2. Paste the TECHNICAL RULES at the end of every prompt.
      3. Then add the per-asset prompt.
        4. Drop the result into the path shown, then run:
         python3 tools/optimize_assets.py
     That crops, resizes and compresses it to match the rest of the game.

Why the technical rules matter (learned the hard way on the current art):
  - The original assets were 1024-1536px for things drawn at 60-460px, so the
    game shipped 63MB of pixels nobody could see.
  - Worse, the subject sat in a huge transparent margin and was NOT centred
    in it - the logo sat 89px above centre, the play button 68px. Every
    position in code was therefore wrong, which is where the alignment drift
    came from. Tight, centred framing avoids all of it.
  - Buttons must ship WITHOUT baked-in text. The game draws the label so it
    can be translated later.


================================================================================
STYLE PREAMBLE  (prepend to every prompt)
================================================================================

Mobile game art in a warm, polished 2.5D cartoon style, inspired by Indian
folk art and the Little Krishna animated series. Soft volumetric lighting,
rich saturated colours, gentle rim light, smooth painterly shading with clean
readable silhouettes. Golden hour warmth, ornate gold filigree accents, deep
blues and marigold oranges. Friendly and child-safe, high production value,
mobile casual game quality.


================================================================================
TECHNICAL RULES  (append to every prompt)
================================================================================

Transparent background (PNG with alpha). The subject must FILL the frame edge
to edge with no more than 2% empty margin, and be exactly centred. No drop
shadow onto the background, no ground plane, no baked-in text or numbers, no
watermark, no border frame. Single object, front-facing, orthographic-ish,
centred composition.

(For BACKGROUNDS only, replace the above with:)
Opaque full-bleed illustration, vertical 9:16 composition, no characters,
no text, no UI elements, no border.

1. KRISHNA SPRITE SHEET  ->  src/assets/characters/krishna_sheet.png
--------------------------------------------------------------------------------
THE most valuable asset to replace. Krishna is currently one static PNG, so he
never changes pose while running or jumping.

Genera create as a SINGLE horizontal strip, 8 frames, each frame exactly 256x384px,
total 2048x384px. Same character, same proportions, same palette, same camera
distance in every frame. Feet on the bottom edge of each frame.

  Frame 1-2  idle: standing, slight breathing bob, peacock feather in hair,
             yellow dhoti, gold jewellery, small blue-skinned toddler
  Frame 3-6  run cycle: four evenly spaced poses of a happy running child,
             arms swinging, dhoti trailing
  Frame 7    jump up: arms raised, legs tucked, body stretched slightly tall
  Frame 8    fall: arms out for balance, legs reaching down

Character: cheerful toddler Krishna, blue skin, big expressive eyes, black
curly hair with a single peacock feather, yellow-gold dhoti, gold bangles and
a beaded necklace.

--------------------------------------------------------------------------------
2. TALL CLIMBING BACKGROUND  ->  src/assets/backgrounds/room_tall.jpg
--------------------------------------------------------------------------------
The level is now several screens tall and scrolls upward, so the background
needs to be tall and to TILE seamlessly at the top and bottom edges.

Prompt: interior wall of a warm traditional Indian village home seen from
floor to high ceiling. Tall vertical composition. Cream and terracotta
plaster walls, carved wooden beams, hanging brass lanterns, small niches with
clay pots, marigold garlands, a lattice window with soft daylight. The wall
texture must continue naturally off the top and bottom edges so the image can
be stacked vertically without a visible seam.

Aspect ratio 9:32 (very tall), e.g. 720x2560.

--------------------------------------------------------------------------------
3. MUSIC / AMBIENCE  (audio, not image)
--------------------------------------------------------------------------------
For an AI music tool. A gentle looping background track, 30-45 seconds,
seamless loop. Light Indian folk instrumentation - bamboo flute lead, soft
tabla rhythm, tanpura drone, occasional finger cymbals. Playful, warm,
unhurried, suitable for a children's mobile game. No vocals. Should sit
quietly under sound effects.

Save as src/assets/audio/music.ogg
